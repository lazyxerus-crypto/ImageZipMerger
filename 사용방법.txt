이미지 ZIP 합치기 — 개발 버전

실행: ZIP을 모두 압축 해제한 뒤 ImageZipMerger.exe를 실행합니다.
libvips-42.dll은 실행파일과 같은 폴더에 두세요.

1. 압축파일 추가 버튼 또는 파일 드롭으로 ZIP/CBZ를 넣습니다.
   이번에 넣은 묶음만 이름의 숫자순(1, 2, 10)으로 정렬하여 기존 목록 아래에 붙입니다.
2. 회차를 드래그하거나 위/아래 버튼으로 이동합니다. 회차 이름을 바꿀 수도 있습니다.
3. 이미지 목록에서 Ctrl/Shift로 여러 장을 선택합니다.
   Ctrl/Shift를 놓고 선택한 이미지 하나를 드래그하면 함께 이동합니다.
   위/아래 버튼 또는 Alt+↑/↓로도 이동할 수 있습니다.
   삭제 또는 Delete는 결과에서 제외하며 원본은 즉시 수정하지 않습니다.
   제외 이미지 표시를 켜서 복원하거나 삭제 취소를 누르세요.
   숨긴 제외 이미지의 위치는 유지하고 보이는 이미지끼리 순서를 바꿉니다.
4. ZIP으로 저장을 누릅니다. 기본 이름은 가장 위 회차의 원본 압축파일 제목입니다.
   변경한 회차·이미지 순서대로 연속 번호를 붙이고 원본 화질을 보존합니다.
   같은 경로에 기존 파일이 있으면 덮어쓰기 확인창이 나타납니다.

원본을 덮어쓰면 저장 결과 하나를 새 작업으로 연결합니다.
이전 회차 구분, 제외 이미지, 삭제 취소 기록은 초기화됩니다.
다른 이름/폴더로 저장하면 기존 작업 상태를 유지합니다.

저장 중은 파랑, 완료는 초록, 주의는 주황, 오류는 빨강으로 아래 로그에 기록합니다.
로그는 최근 100개만 메모리에 남기고 파일로 저장하지 않습니다.
종료하면 로그와 작업 상태는 사라집니다.

추가할 때 원본 ZIP을 복사하지 않으므로 편집 중 원본을 삭제·이동하지 마세요.
미리보기는 현재 이미지 한 장만 보관합니다.
저장 중에만 대상 폴더에 임시 ZIP 하나를 만들며 정상 완료와 처리 가능한 실패 시 정리합니다.
강제 종료·전원 차단·파일시스템 문제로 정리를 실행하지 못하면 임시 파일이 남을 수 있습니다.

지원 입력: 이미지가 들어 있는 ZIP/CBZ. 암호화 ZIP, RAR, 7Z는 미지원.
지원 이미지: JPG, JPEG, PNG, GIF, BMP, TIFF, WebP, AVIF.
GIF 미리보기는 정지 화면입니다. 저장은 원본 바이트를 그대로 복사합니다.
Windows 64비트, .NET Framework 4.5 이상이 필요합니다.
