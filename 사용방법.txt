이미지 ZIP 합치기 — Windows용

실행: 배포 ZIP을 폴더에 모두 압축 해제한 다음 ImageZipMerger.exe를 더블 클릭합니다. libvips-42.dll을 실행파일과 같은 폴더에 두세요. 기존 버전은 닫고 새 폴더의 프로그램을 실행하세요.

1. '압축파일 추가'에서 ZIP 또는 CBZ 파일을 여러 개 선택합니다.
2. 왼쪽에서 회차를 선택한 다음 ↑ / ↓로 합칠 순서를 지정합니다.
   아래 이름 칸에 '1화' 등 원하는 이름을 적고 '이름 적용'을 누릅니다.
   원래 압축파일 이름이 서로 달라도 괜찮습니다.
3. 가운데 이미지 목록을 누르면 오른쪽에서 미리 볼 수 있습니다.
   Ctrl / Shift로 여러 장을 선택한 후 '선택 이미지 삭제' 또는 Delete를 누릅니다.
   '삭제 취소'로 복원할 수 있습니다. '제외한 이미지도 표시'를 켜면
   제외된 이미지를 선택해 '선택 복원'할 수도 있습니다.
4. 'ZIP으로 저장'을 눌러 새 파일로 저장합니다.

이미지는 회차 순서대로 000001_1화.jpg처럼 연속 번호를 붙여 저장합니다.
회차 안에서는 원래 경로/파일명의 숫자 순서로 정렬합니다(1, 2, 10).
이미지를 재인코딩하지 않으므로 원본 화질을 그대로 보존합니다.
원본 ZIP은 수정하지 않습니다. 삭제는 합칠 결과에서만 제외하는 기능입니다.
같은 원본 파일 경로로 저장하는 작업은 차단합니다.

지원 입력: 이미지가 들어 있는 ZIP / CBZ (암호화 ZIP, RAR, 7Z 미지원)
지원 이미지: JPG, JPEG, PNG, GIF, BMP, TIFF, WebP, AVIF
v1.1: WebP / AVIF 미리보기 지원을 추가했습니다.
GIF 미리보기는 정지 화면입니다. 저장 시 원래 파일을 그대로 복사합니다.
이미지 외의 문서나 내부 압축파일은 결과에 포함하지 않습니다.
작업 상태는 프로그램 종료 시 사라집니다. 종료 전 ZIP으로 저장해 주세요.
회차 자체를 빼면 다시 추가해야 합니다. 삭제 취소는 이미지 제외에 적용됩니다.

실행 환경: Windows 64비트, .NET Framework 4.5 이상
소스코드: ImageZipMerger.cs, ModernImage.cs


버전 1.2 추가 기능
- 왼쪽 회차를 선택하면 첫 이미지가 자동으로 표시됩니다.
- 왼쪽 회차를 마우스로 끌어 파란 선 위치에 놓으면 순서가 바뀝니다.
- 목록 위/아래 가장자리로 끌면 자동으로 스크롤됩니다.
- 제외한 이미지를 숨긴 상태에서는 남아 있는 첫 이미지가 표시됩니다.


버전 1.3 변경
- 회차 선택 칸과 이미지 선택 칸의 너비를 서로 교환했습니다(회차 33%, 이미지 25%).


버전 1.4 변경
- 회차 선택 칸을 38%, 이미지 선택 칸을 20%로 조정했습니다.
- 회차 항목 위에 커서를 잠시 올리면 지정한 회차 이름과 원본 압축파일 이름이 표시됩니다.
- 이미지 항목 위에 커서를 잠시 올리면 압축파일 내부의 전체 이미지 이름이 표시됩니다.


버전 1.5: 창과 칸 너비에 맞게 제목, 설명, 입력창, 버튼을 정렬했습니다. 이미지 삭제 버튼은 '삭제', 선택 복원은 '복원', 제외 항목 표시는 '제외 이미지 표시'로 변경했습니다.

버전 1.6: 회차 목록의 이름이 길면 아래에 가로 스크롤바가 나타납니다. 좌우로 끌어서 이름 끝까지 볼 수 있습니다.

버전 1.7: 회차 목록 아래의 빈 공간에서 마우스를 누른 채 위로 끌면 선택 상자로 여러 회차를 선택할 수 있습니다. Delete 또는 회차 빼기로 선택한 회차를 목록에서 제거합니다. 원본 압축파일은 삭제하지 않습니다. Ctrl/Shift 다중 선택, Ctrl+A 전체 선택도 가능합니다. 회차 제거는 삭제 취소 대상이 아니므로 필요하면 원본을 다시 추가하세요.

버전 1.8: 이미지 삭제·복원·삭제 취소 시 회차와 이미지 목록의 스크롤 위치를 유지합니다. 선택한 이미지가 삭제되면 그 자리의 다음 이미지, 마지막이면 이전 이미지를 선택합니다. 회차 제거 시에도 회차 목록의 스크롤 위치를 유지합니다.
