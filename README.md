# ImageZipMerger

여러 ZIP·CBZ 파일에 들어 있는 이미지를 원하는 순서로 골라 하나의 ZIP으로 합치는 Windows 프로그램입니다.

## 주요 기능

- ZIP·CBZ 압축파일 추가(버튼 또는 끌어놓기)
- 회차 목록 관리: 이름 변경, 순서 이동, 빼기
- 이미지 목록 관리: 여러 장 선택, 순서 이동, 제외·복원·삭제 취소
- 이미지 미리보기
- 편집한 순서 그대로 새 ZIP으로 저장

## 실행 방법

1. [최신 배포 다운로드](https://github.com/lazyxerus-crypto/ImageZipMerger/releases/latest) 페이지에서 배포 ZIP을 내려받습니다.
2. ZIP을 모두 압축 해제한 뒤 `ImageZipMerger.exe`를 실행합니다.
3. `libvips-42.dll`이 실행 파일과 같은 폴더에 있어야 합니다.

Windows 64비트, .NET Framework 4.5 이상에서 실행할 수 있습니다.

## 기본 사용 순서

1. `압축파일 추가` 버튼을 누르거나 ZIP·CBZ 파일을 창에 끌어놓습니다.
2. 왼쪽 `회차 선택`에서 작업할 회차를 고릅니다. 필요하면 이름을 바꾸거나 순서를 옮깁니다.
3. 가운데 `이미지 선택`에서 이미지를 고릅니다. 제외할 이미지는 `삭제`하거나 `Delete` 키를 누릅니다. 제외한 이미지는 `복원`하거나 `삭제 취소`로 되돌릴 수 있습니다.
4. 오른쪽에서 선택한 이미지를 미리보기로 확인합니다.

## ZIP 파일 저장 방법

1. `ZIP으로 저장` 버튼을 누릅니다.
2. 저장 위치와 파일 이름을 정하고 저장합니다.
3. 기본 파일 이름은 가장 위 회차의 원본 압축파일 제목입니다.
4. 같은 경로에 같은 이름의 파일이 있으면 덮어쓸지 묻습니다. 원본 파일을 직접 덮어쓰면 저장 결과 하나를 새 작업으로 불러옵니다.
5. 저장 중에는 창을 닫을 수 없습니다. 아래 로그에 파랑(진행 중), 초록(완료), 주황(주의), 빨강(오류)으로 결과가 표시됩니다.

## 자동 정리 옵션 사용 시 주의사항

- 윗줄의 `ZIP 저장 후 자동 정리`를 켜면 저장에 성공했을 때만 원본 압축파일을 삭제하고 대기 회차를 비웁니다.
- 저장이 실패하거나 취소되면 원본 파일과 대기 회차는 그대로 남습니다.
- 저장할 파일과 원본 파일의 경로가 겹치면 삭제를 건너뜁니다.
- 삭제된 원본 파일은 되돌릴 수 없으니 필요한 파일은 미리 백업해 두세요.
- 이 옵션은 기본적으로 꺼져 있습니다. 켜둔 설정은 프로그램을 다시 실행해도 유지됩니다.

## 필수 구성 요소 및 라이선스 안내

- 이미지 미리보기 중 WebP·AVIF 변환에 libvips를 사용합니다. 배포 폴더의 `libvips-42.dll`과 `THIRD-PARTY-LICENSE.txt`를 함께 두세요.
- 지원 입력: 이미지가 들어 있는 ZIP·CBZ(암호화 ZIP, RAR, 7Z는 지원하지 않음).
- 지원 이미지: JPG, JPEG, PNG, GIF, BMP, TIFF, WebP, AVIF. 저장은 재인코딩 없이 원본 그대로 복사합니다.

자세한 사용법은 [사용방법.txt](사용방법.txt)를 참고하세요.
