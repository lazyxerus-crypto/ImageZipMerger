# ImageZipMerger

여러 ZIP·CBZ의 이미지를 원하는 순서로 합치는 Windows 프로그램입니다.

## 실행

[최신 배포 다운로드](https://github.com/lazyxerus-crypto/ImageZipMerger/releases/latest)
배포 ZIP을 모두 압축 해제하고 `ImageZipMerger.exe`를 실행하세요. 같은 폴더의 `libvips-42.dll`이 필요합니다.
Windows 64비트, .NET Framework 4.5 이상을 지원합니다.

## 기능

- 압축파일 추가 및 드롭: 새로 추가한 묶음만 이름의 숫자순(1, 2, 10)으로 정렬하여 기존 목록 뒤에 추가
- 회차 이름 변경, 드래그 및 위/아래 이동, 다중 선택 제거
- 이미지 다중 선택 드래그, 위/아래 버튼 및 Alt+↑/↓ 순서 변경
- 순서 변경 시 가로 스크롤 유지, 같은 이미지 미리보기 재사용
- 이미지 제외·복원·삭제 취소, JPG/PNG/WebP/AVIF 등 미리보기
- 가장 위 회차의 원본 압축파일 제목을 기본 저장 이름으로 사용
- 저장 상태와 오류를 색상 로그로 표시, 기존 파일 덮어쓰기 확인 유지
- 원본 경로에도 저장 가능: 임시 ZIP 완성 후 교체하고 결과 하나를 새 작업으로 연결
- 새 앱 아이콘을 EXE와 프로그램 창에 내장

## 저장과 자원 사용

파일을 추가할 때 원본을 복제하지 않습니다. 메모리에는 파일 정보·순서·제외 상태와 현재 미리보기 한 장을 보관합니다. 저장 전 원본을 삭제하거나 이동하면 이후 읽기와 저장에 실패할 수 있습니다.

저장 시 대상 폴더에 임시 ZIP 하나를 만들고, 모든 원본 읽기가 성공하면 최종 파일로 교체합니다. 정상 완료와 처리 가능한 실패에서 임시 ZIP을 정리합니다. 강제 종료·전원 차단 또는 파일시스템 오류로 정리를 실행하지 못하면 임시 파일이 남을 수 있습니다. 백업이나 로그 파일을 계속 생성하지 않습니다.

**원본을 덮어쓴 뒤에는 저장 결과 하나로 작업을 시작합니다.** 이전 회차 구분, 제외 이미지, 삭제 취소 기록은 초기화됩니다. 새 이름/폴더로 저장할 때는 기존 작업 상태를 유지합니다. 이미지는 재인코딩하지 않고 원본 바이트를 복사합니다.

로그는 최근 100개, 메시지당 최대 약 1,500자만 메모리에 보관하며 종료 시 사라집니다. 작업 상태는 종료 후 복구되지 않습니다.

## 빌드와 테스트

Windows PowerShell에서 `./test.ps1`로 순서·스크롤·정렬·미리보기 재사용·덮어쓰기·실패 시 정리·로그 제한을 검사합니다.
`./build.ps1`은 .NET Framework 컴파일러와 Node.js/npm을 사용하며 결과는 `build/ImageZipMerger-dev.zip`입니다. 이미지 라이브러리는 `@img/sharp-win32-x64@0.35.4`를 사용합니다.

아이콘 원본은 `assets/icon.png`, 다중 해상도 아이콘은 `assets/ImageZipMerger.ico`입니다. PNG에서 ICO를 재생성하려면 `./build-icon.ps1`을 실행합니다.

GitHub Actions는 테스트와 빌드를 수행하고 v1.10 배포 ZIP을 릴리스에 업로드합니다.
